TontineApp

Application mobile pour digitaliser la gestion d'une tontine, du suivi des cotisations à la notification de tour.

FlutterNode.jsREST API

Contexte

La gestion de la tontine se faisait sur un cahier papier, rendant le suivi des cotisations et des tours difficile à partager et à vérifier entre les membres du groupe.

Objectifs

Centraliser le suivi des cotisations, notifier automatiquement chaque membre de son tour, et sécuriser l'historique des échanges pour éviter les litiges.

Solution technique

Application développée en Flutter pour fonctionner sur Android et iOS à partir d'une base de code unique, connectée à une API Node.js. Notifications push pour les rappels de cotisation et de tour.

FlutterNode.jsREST APINotifications push
